HTML 知识体系：从基础到完整掌握

HTML 是前端开发的三大基础技术之一。要系统学习 HTML，最重要的不是死记硬背几十个标签，而是理解：

HTML 如何描述网页的结构、内容、语义，以及它如何与 CSS、JavaScript 和浏览器协作。

我把 HTML 分为 10 个知识模块，从基础语法逐步过渡到实际开发。

一、HTML 完整知识体系

其中前 6 个模块是核心基础，后 4 个模块帮助你从“会写 HTML”进阶到“理解浏览器与规范化开发”。

二、基础语法：HTML 是怎么组成的？

1. HTML、CSS、JavaScript 的关系

一个网页通常由三部分构成：

技术作用例子
HTML内容与结构标题、段落、按钮、图片
CSS外观与布局颜色、尺寸、间距、定位
JavaScript行为与交互点击按钮、提交数据、动态更新
2. HTML 基本文件结构
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>你好，HTML！</h1>
    <p>这是我的第一个网页。</p>
</body>
</html>

各部分含义：

  • <!DOCTYPE html>：声明使用 HTML 标准模式。
  • <html>：根元素，包裹整个 HTML 文档。
  • <head>：提供网页的元信息、标题、资源引用等。
  • <meta>：声明字符编码、视口等信息。
  • <title>：网页标题，通常显示在浏览器标签页。
  • <body>：网页正文内容。

理解一个关键区别：

head 负责描述网页，body 负责承载网页内容。 不过 head 内引用的样式、脚本等也可能影响页面呈现与行为。

3. 元素、标签、属性
<a href="https://example.com" target="_blank">
    访问网站
</a>

拆解：

  • <a>：开始标签。
  • href：属性名。
  • https://example.com：属性值。
  • 访问网站：文本内容。
  • </a>：结束标签。

整个结构称为一个 HTML 元素。

需要掌握的语法概念：

概念示例
普通元素<p>文字</p>
空元素<img src="a.png" alt="图片">
属性id="app"
布尔属性<input disabled>
嵌套<div><p>内容</p></div>
注释<!-- 注释 -->
字符实体&lt;、&amp;

特别注意：并不是所有元素都能随意嵌套，例如 <p> 不能包含另一个 <p>。

三、HTML 内容标签

这是学习初期接触最多的部分。

1. 文本类标签
标签作用
<h1> ~ <h6>六级标题
<p>段落
<span>行内通用容器
<div>通用容器
<strong>重要内容
<em>强调内容
<br>换行
<hr>主题分隔
<pre>保留预格式化文本
<code>代码片段
<blockquote>块级引用

示例：

<h1>HTML 学习笔记</h1>
<h2>第一章：基本概念</h2>

<p>
    HTML 是一种<strong>标记语言</strong>，
    用来描述网页的结构。
</p>

strong 不只是让文字变粗，更重要的是表达语义上的重要性；em 则表达强调。

2. 链接与图片
<a href="https://example.com">
    点击跳转
</a>

<img src="photo.jpg" alt="一只橘猫">

核心知识：

  • href：跳转目标。
  • src：资源地址。
  • alt：图片替代文本。
  • 相对路径与绝对 URL。
  • 页内锚点：href="#section1"。
  • 新窗口：target="_blank"。
3. 列表
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

需要区分：

  • <ul>：无序列表。
  • <ol>：有序列表。
  • <li>：列表项。
  • <dl>、<dt>、<dd>：描述列表。
4. 表格
<table>
    <thead>
        <tr>
            <th>姓名</th>
            <th>成绩</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>小明</td>
            <td>95</td>
        </tr>
    </tbody>
</table>

重点掌握：

table、tr、th、td、thead、tbody、tfoot、colspan、rowspan。

表格用于表达表格数据，不应该拿它作为现代网页的通用布局工具。

四、语义化 HTML：结构不仅是标签

这是 HTML 特别重要的一部分。

假设我们需要创建一个博客页面。

相应的 HTML：

<body>
    <header>网站头部</header>

    <nav>网站导航</nav>

    <main>
        <article>
            <h1>文章标题</h1>
            <section>
                <h2>第一章节</h2>
                <p>文章内容</p>
            </section>
        </article>

        <aside>相关推荐</aside>
    </main>

    <footer>版权信息</footer>
</body>

语义化的核心在于：标签应当表达内容的含义，而不仅仅是方便 CSS 选择。

例如：

<!-- 缺少按钮语义 -->
<div onclick="save()">保存</div>

<!-- 具备按钮语义 -->
<button type="button" onclick="save()">
    保存
</button>

后者原生支持键盘操作、焦点管理及正确的可访问性语义。

五、HTML 表单体系

表单是开发登录、注册、搜索、后台管理系统时最常用的 HTML 功能之一。

1. 核心表单标签
标签作用
<form>表单容器
<input>单行输入及多种控件
<textarea>多行文本
<select>下拉选择
<option>选择项
<button>按钮
<label>表单控件标签
<fieldset>分组
<legend>分组标题
2. 一个可交互的表单

对应 HTML 的核心结构：

<form action="/register" method="post">
    <label for="username">用户名</label>
    <input
        id="username"
        name="username"
        type="text"
        required
    >

    <label for="password">密码</label>
    <input
        id="password"
        name="password"
        type="password"
        required
    >

    <button type="submit">注册</button>
</form>

表单部分除了标签本身，还必须学会以下知识：

  • type：text、password、number、email、date、checkbox、radio、file 等。
  • name：字段提交时使用的名称。
  • value：字段的值。
  • action 和 method：数据提交地址与 HTTP 方法。
  • required、minlength、pattern：原生表单校验。
  • disabled 与 readonly：两种不同的限制机制。
  • enctype：表单数据编码，尤其是上传文件时。

尤其注意：id 主要用于标识元素，name 才是普通表单数据提交时使用的字段名。

六、多媒体与资源引用

HTML 不只有文字，还可以承载各种外部资源。

功能标签
图片<img>
音频<audio>
视频<video>
字幕<track>
资源格式备选<source>
嵌入页面<iframe>
响应式图片<picture>
适配式图片资源<img srcset>
外部样式表<link>
JavaScript 脚本<script>

示例：

<video controls width="640">
    <source src="movie.mp4" type="video/mp4">
    您的浏览器不支持视频播放。
</video>

进阶需要理解资源加载性能，例如图片懒加载 loading="lazy"、脚本 defer、async 与 type="module"。

七、HTML5 的其他重要能力

除了语义化元素和多媒体，现代 HTML 还包括不少原生能力。

例如：

<details>
    <summary>什么是 HTML？</summary>
    <p>HTML 是超文本标记语言。</p>
</details>

这一模块还包括：

  • <dialog>：原生对话框。
  • <progress>：任务进度。
  • <meter>：范围内的测量值。
  • data-*：自定义数据属性。
  • <template>：可复用的惰性 HTML 模板。
  • <canvas>、<svg>：图形相关能力。

注意：Web Storage、WebSocket、Geolocation 等通常属于浏览器 Web API，不是 HTML 标签本身，需要结合 JavaScript 学习。

八、浏览器如何解析 HTML？

这是从基础开发进入原理的重要一步。

这里最重要的概念是 DOM（Document Object Model，文档对象模型）。

例如 HTML：

<div id="app">
    <h1>标题</h1>
    <p>内容</p>
</div>

浏览器会将它解析成对象树：

div#app
├── h1
│   └── "标题"
└── p
    └── "内容"

JavaScript 可以通过 DOM API 查找和修改这些节点。

const h1 = document.querySelector("h1");
h1.textContent = "新的标题";

这一模块建议掌握：

  • HTML 解析与 DOM 树。
  • DOM 节点、元素、属性的区别。
  • JavaScript 操作 DOM。
  • DOMContentLoaded 与 load 事件。
  • CSSOM、渲染树、布局与绘制的基本概念。

九、无障碍、SEO 与规范

学习 HTML 不仅是为了让网页“能显示”，更是让网页容易被用户、浏览器和搜索引擎正确理解。

无障碍（Accessibility）：使用正确标签、关联表单标签、提供图片替代文本、保持合理的标题层级，让键盘用户与辅助技术用户也能正常使用网页。

SEO（搜索引擎优化）：合理设置 <title>、meta description、标题层级、语义结构、链接文本等，有助于搜索引擎理解页面，但不保证具体排名。

安全与规范：理解 HTML 转义、禁止把不可信文本直接拼入 innerHTML、外部资源引用的风险，以及 HTML 结构校验。

十、HTML 的工程实践

在实际项目里，你还需要掌握 HTML 与开发工具、框架的协作。

例如 Vue：

<template>
  <div class="user-card">
    <h2>{{ username }}</h2>
    <button @click="changeName">
      修改名字
    </button>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const username = ref('小明')

function changeName() {
  username.value = '小红'
}
</script>

Vue 模板与 HTML 很相似，但 Vue 增加了插值表达式、指令、组件等模板语法。

先理解 HTML，再学 Vue 的 v-if、v-for、v-model、@click，会容易很多。

最重要的学习建议

HTML 的知识广度不算特别大，不必等到把所有标签背熟才学习 CSS 和 JavaScript。

比较高效的方式是：

  1. 首先掌握 HTML 文档结构、常用标签、表单与语义化。
  2. 接着结合 CSS，练习把 HTML 内容变成实际网页。
  3. 再结合 JavaScript 理解 DOM 和用户交互。
  4. 最后在 Vue 等框架中理解组件模板、渲染和数据绑定。

学习 HTML 的核心不是记住所有标签，而是形成一套判断方式：当前内容是什么、应该使用什么元素、需要哪些属性、浏览器如何理解它。

下一步最适合正式从 HTML 基础语法 开始，依次深入讲解文档结构、标签和元素、属性、嵌套规则、空元素、字符实体，并结合实际代码逐个练习。
