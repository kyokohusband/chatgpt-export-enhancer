会话导出增强器

整段会话或勾选的消息，一键导出为可离线阅读的 HTML / Markdown / JSON / 纯文本。

导出默认值

行为

Python 引擎把 CPython 编译成 WebAssembly 打进插件，直接用桌面端那份转换代码，因此导出的文件和桌面程序转换出来的逐字节相同。代价是插件体积大一些，首次导出会多等 1~2 秒。

点一下确认插件内的 Python 能正常启动

使用方式

  1. 在对话页面右下角点蓝色气泡（或按 Alt + Shift + E）。
  2. 选「整段会话」直接导出；选「选中的消息」后勾选需要的问答再导出。
  3. 导出的 HTML 已经把组件运行时、代码高亮、右侧目录都内嵌好了，双击离线打开就是可交互页面。
  4. 如果关掉了「直接产出可交互页面」，得到的是静态 HTML，可再拖进「导出增强器」桌面程序转换。

仅在 ChatGPT 页面启用。
